## **🎯College Portal APIs With Real-Time Notification Service**
This project demonstrates a real-time notification service using Spring Boot for the backend and React for the frontend. The service allows for real-time updates via WebSockets, ensuring that notifications are pushed to the client instantly.

## **`⛓Project Structure`**
      my-spring-boot-app/
      ├── src/main/java/                    # Java source code (Controllers, Services, Repositories)
      │   └── com/example/demo/
      │       └── DemoApplication.java      # Main entry point (@SpringBootApplication)
      ├── src/main/resources/               # Non-Java configuration and assets
      │   ├── static/                       # Static web resources (HTML, CSS, JS)
      │   ├── templates/                    # Server-side UI templates (Thymeleaf, FreeMarker)
      │   └── application.properties        # Main application configuration file
      ├── src/test/java/                    # Unit and integration tests
      │   └── com/example/demo/

      ├── JRE System Library                # Configured Java Runtime Environment
      ├── Maven Dependencies                # Automatically downloaded JAR files managed by Maven
      ├── target/                           # Compiled classes and build outputs (generated by Maven)
      └── pom.xml                           # Maven project configuration and dependencies file
